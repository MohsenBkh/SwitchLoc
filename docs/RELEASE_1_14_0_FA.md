# نسخه ۱.۱۴.۰ — غنی‌سازی بانک آفلاین مکان‌های اردبیل

**تاریخ:** ۱۶ آبان ۱۴۰۵ (۲۰۲۶-۱۱-۰۷) · **نسخه:** `1.14.0`
**درخواست کاربر:** «بانک مکانی آفلاین اردبیل را کامل/غنی کن تا «نام پست» در
کارتابل خاموشی بیشتر و بهتر به مکان واقعی وصل شود — شهرها هم باشند نه فقط
آبادی، همراه نام‌های جایگزین فارسی، جمعیت و پوشش بیشتر، با منبع و مجوز روشن
برای هر رکورد؛ در زمان اجرا هم کاملاً آفلاین بماند.»

> **خلاصهٔ یک‌خطی:** بانک آفلاین از ۱٬۰۰۶ روستا به **۱٬۰۳۲ مکان** (۲۲ شهر +
۷ شهر کوچک + ۱٬۰۰۳ روستا) با **۲۹۰ نام جایگزین** و **۲۶ جمعیت واقعی** رسید؛ سه باگ
> پنهان تطبیق نام رفع شد (از جمله حذف شدن «آ») و در نتیجه روی دادهٔ واقعی پروژهٔ
> کوثر، «نام پست»های حل‌شده از **۳۶ به ۵۲** از ۱۳۳ رسید — بدون هیچ مختصات
> ساختگی و بدون هیچ فراخوانی شبکه‌ای در مسیر اجرا.

---

## ۱) مسئله چه بود؟

در کارتابل بازبینی خاموشی، هر رخداد یک «نام پست» دارد (مثلاً
«باغات سکرآباد شماره ۴۰ دربندی»). برنامه این نام را آفلاین در بانک مکان‌ها
جست‌وجو می‌کند و اگر پیدا شود، نقطهٔ پیشنهادی روی نقشه می‌گذارد. بانک قبلی
سه کاستی داشت:

1. **فقط ۱٬۰۰۶ روستا** داشت؛ هیچ شهری در آن نبود، پس «خلخال» یا «پارس‌آباد»
   هم پیدا نمی‌شد و نوع مکان همه‌جا `village` بود.
2. **صفر نام جایگزین** داشت؛ نوشتارهای عملیاتی رایج («فارس‌آباد» برای
   «پارس‌آباد»، «ولتان» برای «اولتان»، «مشگين» برای «مشگین») کشف نمی‌شد.
3. **باگ نرمال‌سازی**: تابع `normalize_place_name` حرف «آ» را دور می‌ریخت
   (آ ← حذف)، بنابراین «فيروز اباد» هرگز به «فیروزآباد» نمی‌رسید؛ و تطبیق
   جزئی از **میان** یک واژه شروع می‌شد، پس «امير اباد» به «میراب» و
   «سالن ورزشي زرج اباد» به «رز» وصل می‌شد (خطای مثبت کاذب در کارتابل).

## ۲) چه کاری انجام شد؟

### الف) لایهٔ شهرها با جمعیت (GeoNames)
۲۶ شهر/شهرک واقعی استان از `cities1000` (GeoNames، CC BY 4.0) اضافه شد،
با **مختصات واقعی و جمعیت** و **بدون درون‌یابی**. هر ردیف برچسب منبع خودش را
دارد. ۱۲ ردیف با سکونتگاه‌های موجود **ادغام** شد (همان مکان، نه کپی دوم):

| شهر | جمعیت | شهر | جمعیت |
|---|---:|---|---:|
| اردبیل | ۴۱۰٬۷۵۳ | نیر | ۵٬۸۷۳ |
| پارس‌آباد | ۱۰۲٬۹۹۶ | امین‌جان | ۵٬۷۵۷ |
| مشگین‌شهر | ۷۴٬۱۰۹ | هشتجین | ۵٬۷۲۵ |
| خلخال | ۵۱٬۰۲۴ | سرعین | ۵٬۴۵۹ |
| گرمی | ۲۸٬۹۶۷ | گیوی | ۷٬۱۰۱ |
| بیله‌سوار | ۱۴٬۰۰۰ | آبی‌بیگلو | ۶٬۵۱۵ |
| نمین | ۱۳٬۶۵۹ | جعفرآباد | ۷٬۲۲۶ |
| اصلاندوز | ۶٬۳۴۸ | لاهرود / کلور / … | — |

نقطه‌ها با چندضلعی استان **کلیپ** می‌شوند تا هیچ شهر بیرون‌استانی وارد نشود.

### ب) نام رسمی، شهرستان و دهستان (تقسیمات کشوری)
فهرست رسمی استان (منبع AMAR، بازتوزیع‌شده در مخزن MIT
`ahmadazizi/iran-cities` نسخهٔ ۳) فقط برای سه کار استفاده می‌شود:
**اعتبارسنجی نام، املای نمایشی و پرکردن شهرستان/دهستان**. این فهرست
**مختصات ندارد** و هیچ مختصاتی از آن ساخته نشده:

* املای نمایشی از فهرست رسمی گرفته می‌شود: مشگين ← مشگین، سَر عِين ← سرعین.
* شهرستان/دهستانِ خالی پر می‌شود، اما **فقط** وقتی نام و شهرستان مطابقت دارد؛
  اگر یک نام در چند شهرستان تکرار شده باشد و شهرستانِ ردیف معلوم نباشد،
  دهستان **خالی می‌ماند** (حدس زده نمی‌شود).
* نوع مکان به `city` ارتقا می‌یابد اگر همان نام در فهرست رسمی «شهر» باشد.

### ج) نام‌های جایگزین (۲۹۰ ردیف)
نام‌های فارسی و لاتین از GeoNames برای همان مکان‌ها ثبت شد تا نوشتارهای
عملیاتی پیدا شوند: `Farsabad`/`پارس آباد` برای پارس‌آباد، `Owltan`/`اولتان`،
`Kheyav`/`خیاو` برای مشگین‌شهر، `Shahrud`/`کلور` …

> **نکتهٔ طراحی:** برای گونه‌های نوشتاری «آ/ا»، «ی/ي»، «ک/ك» و فاصله‌ها
> **ردیف alias ساخته نمی‌شود**؛ خودِ کلید تطبیق این حروف را یکی می‌کند
> (`KEY_SCHEMA_VERSION=2`). ردیف تکراری فقط حجم بانک را بالا می‌برد.

### د) رفع سه باگ تطبیق نام
1. **«آ» حذف نمی‌شود بلکه یکسان می‌شود:** آ/أ/إ/ٱ ← ا، ي ← ی، ك ← ک،
   ة/ۀ ← ه، ؤ ← و، نیم‌فاصله ← فاصله. با ارتقای `KEY_SCHEMA_VERSION` به ۲،
   کلیدهای قدیمی بانک **درجا و بی‌خطر** بازسازی می‌شوند (مهاجرت `_migrate`).
   نتیجه: «فيروز اباد» ← «فیروزآباد» با اطمینان **زیاد (۰٫۹۷)**.
2. **تطبیق جزئی فقط روی مرز واژه:** نام مکان باید ابتدا/انتها یا کل
   یک بازهٔ توکن از پرس‌وجو را بپوشاند. «سالن ورزشي زرج اباد» → «زرج آباد»
   (۰٫۶۲) ولی «ورزشي» → هیچ. «امير اباد» → هیچ (قبلاً «میراب»).
3. **بازه‌های توکن چندواژه‌ای:** «زاويه زرج اباد» (۰٫۶۸) و
   «باغات سکرآباد شماره ۱۰ سميعي» (۰٫۵۶) درست به «زرج آباد» و «سکرآباد»
   می‌رسند؛ امتیاز با نسبت پوشش کنترل می‌شود تا نام‌های کوتاه باعث تطبیق
   بی‌ربط نشوند (`min(0.8, 0.4 + 0.4·share)`).

## ۳) نتیجه روی دادهٔ واقعی (پروژهٔ کوثر، ۱۳۳ «نام پست» یکتا)

| وضعیت | قبل | بعد |
|---|---:|---:|
| «زیاد» (تطبیق کامل/کلید فشرده) | ۱۵ | **۲۳** |
| «متوسط» (تطبیق جزئی مرز واژه) | ۲۱ | **۲۹** |
| «هیچ» (پیشنهاد نمی‌شود) | ۹۷ | **۸۱** |
| **مجموع حل‌شده** | **۳۶** | **۵۲** |

* **۱۹ نام** تازه حل شد: ۱۶ سایت «سکرآباد» (باغات شماره ۱۰ تا ۱۳۰، پمپاژ آب
  شرب، مسیر باغات)، «زاويه زرج اباد»، «نقي ساعدي زرج آباد»،
  «سايت موبايل GSM زرج آباد»، «شهرك مسكوني جديد زاويه زرج آباد»،
  «افشار عليا».
* **۸ تطبیق غلط حذف شد** که مهم‌ترینشان «يوزناب ← زناب» با امتیاز ۰٫۶۷ بود
  (دو آبادی متفاوت — این خطا چاه کشاورزی را به روستای همسایه می‌برد).
  بقیه: «چاه كشاورزي … ← رز» (۰٫۰۸)، «دامداري نور محمد عيوضي ← نو شهر»
  (۰٫۰۹)، «قرارداد اويول ← ویو» (۰٫۲۳).

هیچ‌کدام از نام‌های حل‌شده با مختصات ساختگی همراه نشد؛ مکان پیشنهادی همچنان
فقط **پیشنهاد** است و انتساب زون با تأیید مهندس ثبت می‌شود.

## ۴) پوشش و آنچه هنوز کم است

| شاخص | مقدار |
|---|---|
| مکان‌ها | ۱٬۰۳۲ (شهر ۲۲ / شهر کوچک ۷ / روستا ۱٬۰۰۳) |
| نام جایگزین | ۲۹۰ |
| مکان دارای جمعیت | ۲۶ (فقط شهرها) |
| نام آبادی رسمی یکتا | ۱٬۰۰۹ از ۱٬۷۶۸ = **۵۷٫۱٪** |
| نام شهر رسمی یکتا | ۱۹ از ۳۶ |
| نام‌های بانک بیرون از فهرست رسمی | ۴ |

**۸۴۰ جای رسمی** هنوز مختصات ندارد (۸۳۳ آبادی + ۱۷ شهر) و در
`data/geography/ardabil_missing_places.csv` فهرست شده است؛ ستون‌های `lat`/`lon`
عمداً خالی‌اند. شهرهای غایب: آراللو، اردیموسی، اسلام‌آباد، تازه‌کندانگوت،
ثمرین، زهرا، عنبران، فخرآباد، قصابه، کوراییم، مغان‌سر، هیر و پنج ردیف
«اردبیل ۱..۵» (مناطق شهرداری، نه شهر). این‌ها در `cities1000` نیستند.

**۲۲ ردیف شهر/شهرک `district` خالی دارند و این عمدی است:** در سلسله‌مراتب AMAR
شهر زیر «بخش» است نه «دهستان»؛ شهرستانِ هر ۱٬۰۳۲ ردیف پر است.

> **محدودیت صریح:** سایت‌های BTS، دامداری‌ها، کارگاه‌ها و ۶۱۸ نامزد با
> اطمینان پایین **منبع رسمی ندارند** و وارد بانک نشدند. نام‌هایی مثل
> «میکائیل‌آباد»، «لیکوان» (در فهرست رسمی هم نیستند) و «وردی تونل‌های ۱ تا ۱۰»
> فقط با لایهٔ GIS محلی یا بازبینی دستی حل می‌شوند.

## ۵) بازتولیدپذیری

همهٔ ورودی‌ها یا در مخزن‌اند یا از منبع آزاد قابل تهیه، و خروجی **بایت‌به‌بایت
قابل بازسازی** است (آزمون‌شده: ساخت دوباره از بانک اصلیِ `HEAD` با فهرست رسمی
داخل مخزن، همان ۱٬۰۳۲ مکان و ۲۹۰ نام جایگزین را می‌دهد):

```bash
# ۱) غنی‌سازی (--dry-run برای پیش‌نمایش)
PYTHONPATH=src python scripts/enrich_ardabil_gazetteer.py \
    --geonames cities1000.json \
    --boundary data/geography/ardabil_boundary.geojson \
    --official-csv data/geography/official_ardabil_places.csv \
    --database data/geography/ardabil_places.sqlite --report /tmp/enrich.json

# ۲) گزارش شکاف پوشش + ساخت CSV تکمیل (کاملاً آفلاین)
PYTHONPATH=src python scripts/ardabil_place_gap_report.py \
    --official-csv data/geography/official_ardabil_places.csv \
    --database data/geography/ardabil_places.sqlite \
    --csv data/geography/ardabil_missing_places.csv

# ۳) پرس‌وجوی سریع بانک از خط فرمان
python -m switchloc places "زرج آباد" "خلخال" --limit 2
python -m switchloc places --stats
```
