# یادداشت انتشار نسخه ۱.۲۱.۰ — نمایش، پروژه و راهنمای کاربر

- بازترسیم تغییر دسته کلیدها با تأخیر کوتاه تجمیع شد تا به‌ازای هر زیرکلید نقشه مجدداً رسم نشود؛ بازترسیم نهایی همچنان تابع اندازه شبکه و لایه‌هاست.
- خلاصه رخدادهای ذخیره‌شده پس از بازگشایی پروژه در پنل خاموشی نمایش داده می‌شود. اجرای توپولوژی برای بازبینی مکان‌ها لازم است. خطای خواندن آشکار گزارش می‌شود. در آزمون فایل واقعی، ۳۵۳۱ رخداد پس از پشتیبان SQLite و بازگشایی بازیابی شدند. فایل ZIP پروژه اضافه نشده است؛ SQLite با مکانیزم backup یک نسخه مستقل می‌سازد.
- پیش‌فرض واحد انرژی پردازش خاموشی MWh است؛ این انتخاب تأیید واحد فایل نیست.
- راهنمای PDF از منوی Help و در build_assets/help قرار دارد. برای تولید مجدد از scripts/build_user_guide.py و کتابخانه‌های reportlab، arabic-reshaper و python-bidi استفاده کنید.
- توزیع رنگی فقط روی یال فیدرهای انتخابی رسم می‌شود؛ مختصات بدون فیدر مشخص در فیلتر فیدر وارد توزیع نمی‌شوند. پیش‌فرض خط خاموشی تا مرکز زون خاموش است و تنظیم ذخیره‌شده قبلی حفظ می‌شود. رنگ، اندازه و نماد UTM قابل تنظیم شد.
- مقایسه دو روش با شبکه واقعی کوثر در docs/COMPARISON_EENS_FA.md ثبت شد؛ این یک سناریو با بار تخمینی است، نه اعتبارسنجی همه پروژه‌ها.
- آزمون‌های هدفمند بدون Qt موفق بودند؛ اجرای رابط گرافیکی واقعی و ساخت Windows در این محیط به علت نبود libGL قابل تأیید نیست. کارایی نهایی در شبکه کاربر باید روی سیستم مقصد بررسی شود.
