# ساخت راهنمای فارسی

منبع اصلی: `SwitchLoc_Feeder_Tutorial_FA.tex`؛ راهنمای داخل نرم‌افزار: `build_assets/help/SwitchLoc_Guide_FA.pdf`. فایل PDF همراه برنامه بسته‌بندی می‌شود و برای مشاهده آن نیازی به نصب ابزار ساخت نیست.

## ساخت از منبع با XeLaTeX

در محیط دارای XeLaTeX، xepersian و بسته‌های استفاده‌شده در منبع:

```sh
python scripts/build_feeder_tutorial.py
```

این روش متن اصلی را مستقیماً کامپایل و تنها در صورت موفقیت جایگزین PDF برنامه می‌کند. در محیط فعلی این مسیر آزمایش نشده است.

## ساخت جایگزین با Typst و MathJax

این مسیر متن و جدول‌های منبع را بازچینش و روابط ریاضی را به شکل برداری SVG در PDF درج می‌کند. روابط برداری هستند، نه متن ساده یا عکس صفحه؛ اگر رابطه‌ای قابل پردازش نباشد، ساخت متوقف می‌شود. در رابطه متغیر دودویی تنها عبارات توضیحی داخل آکولاد به انگلیسی درج شده‌اند تا حروف فارسی در موتور ریاضی جدا نشوند؛ معنای فارسی در متن کنار رابطه موجود است. فهرست فصل‌ها بدون شماره صفحه و ترسیم تزئینی روی جلد ساده‌سازی شده‌اند. منبع TeX همچنان مرجع ویرایش است.

```sh
python -m pip install typst pylatexenc arabic-reshaper python-bidi
npm install --no-save mathjax-full@3.2.2
python scripts/build_tutorial_pdf.py
```

سپس PDF حاصل را از نظر متن راست‌به‌چپ، جدول‌ها و روابط بصری بررسی کنید. با این روش اسناد Word تولید نمی‌شود و رابطه‌ها داخل PDF قابل ویرایش متنی نیستند. `scripts/build_user_guide.py` مولد نمایه قدیمی است و خروجی جداگانه می‌سازد تا راهنمای جدید را بازنویسی نکند.

اعداد مطالعه موردی فایل‌های ۳ تا ۷ در این محیط مجدداً بازتولید نشده‌اند؛ هشدار داده‌ای متن باید حفظ شود.
