# یادداشت انتشار SwitchLoc 1.9.4

## مدیریت چرخه عمر پروژه

در این نسخه قابلیت مدیریت پروژه به منوی File افزوده شده است:

- **پروژه جدید (Ctrl+N):** ایجاد فایل مستقل SQLite برای پروژه؛ مسیر انتخابی به‌عنوان مقصد ورود بعدی داده‌های GIS استفاده می‌شود.
- **بازکردن پروژه (Ctrl+O):** بازکردن پروژه موجود؛ در صورت وجود تغییرات ذخیره‌نشده، ابتدا تصمیم کاربر گرفته می‌شود.
- **ذخیره (Ctrl+S):** ثبت نهایی تراکنش‌ها و checkpoint کردن WAL پایگاه داده پروژه جاری.
- **ذخیره با نام جدید (Ctrl+Shift+S):** ایجاد نسخه مستقل از پایگاه داده با SQLite Online Backup و انتقال پروژه فعال به مسیر جدید.
- **ذخیره هنگام خروج:** اگر تغییرات ذخیره‌نشده وجود داشته باشد، گزینه‌های ذخیره، خروج بدون ذخیره یا انصراف نمایش داده می‌شود. انصراف مانع بسته‌شدن برنامه می‌شود.

## حفاظت از داده‌ها

- در Save As از کپی خام فایل SQLite استفاده نشده؛ SQLite Backup API برای سازگاری با WAL استفاده می‌شود.
- تغییر مسیر پروژه پس از تکمیل موفق عملیات ذخیره انجام می‌شود.
- اگر ذخیره با خطا مواجه شود، مسیر پروژه فعال تغییر نمی‌کند و برنامه اجازه خروج یا جایگزینی پروژه را نمی‌دهد.
- تغییرات ذخیره‌نشده در عملیات ورود GIS، تحلیل خاموشی، توپولوژی، جایابی و تغییر استایل پروژه علامت‌گذاری می‌شوند.
