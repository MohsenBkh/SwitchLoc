# بانک جغرافیایی آفلاین استان اردبیل

فایل `ardabil_places.sqlite` بانک عملیاتی مکان‌های استان اردبیل است که برنامه در
زمان اجرا فقط به‌صورت محلی می‌خواند؛ **هیچ فراخوانی شبکه‌ای در مسیر اجرا وجود
ندارد**. نسخهٔ ۱٫۱۴ این بانک غنی‌سازی شده است.

## محتوای بانک (نسخهٔ فعلی)

| شاخص | مقدار |
|---|---|
| مکان‌ها | **۱٬۰۳۲** |
| نوع: شهر / شهر کوچک / روستا | ۲۲ / ۷ / ۱٬۰۰۳ |
| نام‌های جایگزین (alias) | ۲۹۰ |
| مکان‌های دارای جمعیت | ۲۶ |
| پوشش نام‌های آبادی رسمی (یکتا) | ۱٬۰۰۹ از ۱٬۷۶۸ — **۵۷٫۱٪** |
| پوشش نام شهرهای رسمی (یکتا) | ۱۹ از ۳۶ (۲۱ ردیف) |
| محدودهٔ مختصات | استان اردبیل (کلیپ‌شده با چندضلعی استان) |

مکان‌های بزرگ شهری با جمعیت (نمونه): اردبیل ۴۱۰٬۷۵۳؛ پارس‌آباد ۱۰۲٬۹۹۶؛
مشگین‌شهر ۷۴٬۱۰۹؛ خلخال ۵۱٬۰۲۴؛ گرمی ۲۸٬۹۶۷؛ بیله‌سوار ۱۴٬۰۰۰؛ نمین ۱۳٬۶۵۹؛
جعفرآباد ۷٬۲۲۶؛ گیوی ۷٬۱۰۱؛ آبی‌بیگلو ۶٬۵۱۵؛ اصلاندوز ۶٬۳۴۸؛ نیر ۵٬۸۷۳؛
امین‌جان ۵٬۷۵۷؛ هشتجین ۵٬۷۲۵؛ سرعین ۵٬۴۵۹.

## منبع هر ردیف (بدون استثنا)

ستون `places.source` برای **هر** رکورد پر است و هیچ ردیف بی‌منبعی در بانک
نیست:

| مقدار `source` | تعداد | مجوز |
|---|---|---|
| `OSM / Ardabil Gazetteer v2 (high-confidence candidate)` | ۱٬۰۰۶ | ODbL 1.0 (الزام انتساب) |
| `GeoNames cities1000 (CC BY 4.0)` | ۲۶ | CC BY 4.0 (الزام انتساب) |

* **OSM** — بانک اولیه: سکونتگاه‌های دارای مختصات از پایگاه بازبینی
  `ardabil_gazetteer_v2_review.sqlite`؛ فقط نامزدهایی که به یک شناسهٔ سکونتگاه
  رسمی متصل و برچسب `high` داشتند (یک نقطه برای هر شناسه).
* **GeoNames** — شهرهای بزرگ استان از `cities1000` (واقعی، بدون درون‌یابی)
  همراه جمعیت؛ مختصات GeoNames (بر پایهٔ GeoNames/OSM) با دقت ~۱۰۰ متر است و
  **نقشه‌برداری رسمی نیست**.
* **تقسیمات کشوری (نام و سلسله‌مراتب)** — فهرست رسمی استان از مخزن
  `ahmadazizi/iran-cities` (مجوز MIT، دادهٔ AMAR) فقط برای **اعتبارسنجی نام،
  املای نمایشی و پرکردن شهرستان/دهستان** استفاده شده است؛ این فهرست
  مختصات ندارد و هیچ مختصاتی از آن ساخته نشده.
* **مرز استان** — `ardabil_boundary.geojson` از
  `ssepehrnoush/Iran-geojson-map-boundaries` (MIT) برای کلیپ کردن نقاط.
* **فهرست رسمی استان** — `official_ardabil_places.csv` (۱٬۸۹۵ ردیف: ۱۱ شهرستان،
  ۱٬۸۵۹ آبادی، ۳۶ شهر) زیرمجموعهٔ استان از همان منبع MIT/AMAR. **فقط نام و
  سلسله‌مراتب، بدون مختصات**؛ برای اعتبارسنجی نام، املای نمایشی، پرکردن
  شهرستان/دهستان و ساخت گزارش شکاف به‌صورت آفلاین.

۶۱۸ نامزد با اطمینان پایین و نامزدهای فاقد اتصال به سکونتگاه رسمی در این بانک
وارد نشده‌اند. نام‌های عملیاتی نظیر سایت BTS، دامداری و تأسیسات خصوصی ممکن است
در بانک آبادی‌ها نباشند و نیازمند لایهٔ GIS یا بازبینی دستی‌اند.

**۲۲ ردیف شهر/شهرک دهستان خالی دارند و این درست است:** در سلسله‌مراتب AMAR
شهر زیر «بخش» است نه «دهستان»، پس ستون `district` برای شهر معنا ندارد؛
شهرستانِ همهٔ ۱٬۰۳۲ ردیف پر است.

## «چه چیزهایی کم است؟» — `ardabil_missing_places.csv`

`ardabil_missing_places.csv` (۸۴۰ ردیف) فهرست جاهایی است که **در تقسیمات
کشوری رسمی هستند ولی مختصاتشان در بانک نیست** (۸۳۳ آبادی + ۱۷ شهر). ستون‌های
`lat`/`lon` عمداً خالی‌اند: مختصات ساختگی وارد نمی‌شود. تیم محلی می‌تواند آن را
از GIS خود پر کند و با `PlaceGazetteer.import_csv` به بانک برگرداند.

شهرهای غایب: آراللو، اردیموسی، اسلام‌آباد، تازه‌کندانگوت، ثمرین، زهرا، عنبران،
فخرآباد، قصابه، کوراییم، مغان‌سر، هیر و پنج «اردبیل ۱..۵» (مناطق شهرداری، نه
شهر). این‌ها در `cities1000` موجود نیستند، پس با منبع قانونی وارد نشدند.

## بازسازی بانک (offline تولید، online یک‌بار)

```bash
# ۱) از بانک اولیه نسخهٔ غنی‌شده بساز
PYTHONPATH=src python scripts/enrich_ardabil_gazetteer.py \
    --geonames <cities1000.json> \
    --boundary data/geography/ardabil_boundary.geojson \
    --official-csv data/geography/official_ardabil_places.csv \
    --database data/geography/ardabil_places.sqlite \
    --report /tmp/enrich.json          # افزودن --dry-run برای پیش‌نمایش
# (جایگزین: --official-dir <iran-cities>/releases/v3.0/csv)

# ۲) گزارش شکاف پوشش + CSV تکمیل
PYTHONPATH=src python scripts/ardabil_place_gap_report.py \
    --official-csv data/geography/official_ardabil_places.csv \
    --database data/geography/ardabil_places.sqlite \
    --csv data/geography/ardabil_missing_places.csv
```

هر دو اسکریپت فقط فایل محلی می‌خوانند و روی کپی بانک هم قابل اجرا هستند.
ساخت دوباره از بانک اصلی همراه مخزن با همین ورودی‌ها، همان ۱٬۰۳۲ مکان و ۲۹۰
نام جایگزین را می‌دهد (بازتولیدپذیری آزمون‌شده).

## استفاده در برنامه

* `switchloc.geography.places.PlaceGazetteer` — جست‌وجوی آفلاین نام و
  نام‌های جایگزین، برگرداندن مختصات WGS84، `find_near`، `nearby_county`،
  `import_csv` و `stats`.
* `switchloc places "زرج آباد" "خلخال" --stats` — پرس‌وجوی سریع از خط فرمان.
* در بازبینی خاموشی، مکان پیشنهادی فقط **پیشنهاد** است و انتساب زون تنها با
  تأیید مهندس ثبت می‌شود.

## قاعده‌های تطبیق نام (v1.14)

1. نرمال‌سازی: «آ/ا/ٱ»، «ی/ي»، «ک/ك»، «ة/ه»، «ؤ/و»، نیم‌فاصله و فاصله‌ها یکی
   می‌شوند (`normalize_place_name`، `compact_place_name`).
2. تطبیق کامل نام ← «زیاد» (۱٫۰۰)؛ تطبیق کلید فشرده ← «زیاد» (۰٫۹۷).
3. تطبیق جزئی **فقط** روی مرز واژه‌ها؛ زیررشتهٔ داخل یک واژه پذیرفته نمی‌شود
   (رفع باگ «امير اباد» ← «میراب»).
4. اگر هیچ مکانی پیدا نشد، نتیجه خالی است؛ حدس زده نمی‌شود.
